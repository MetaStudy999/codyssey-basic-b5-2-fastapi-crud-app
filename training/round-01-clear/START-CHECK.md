# B5-2 — 시작 전 지식 체크

이 문서는 B5-2를 시작하기 전에 **FastAPI CRUD를 이해하기 위한 DB와 Web 기초가 준비되어 있는지** 확인하는 자가진단입니다. 공식 평가나 Runtime Gate가 아닙니다.

## 선행 학습

- **필수 선행 미션:** 없음
- **권장 선행 미션:** B5-1, B4-1
- **있으면 좋은 선행 지식:** HTTP Request/Response, Form, CRUD, SQL, Python Web 기초

## 자가진단

- [ ] Table/Row/Column과 Primary Key의 의미를 대략 설명할 수 있다.
- [ ] `SELECT`, `INSERT`, `UPDATE`, `DELETE`가 각각 무엇을 하는지 알고 있다.
- [ ] CRUD(Create/Read/Update/Delete)의 의미를 알고 있다.
- [ ] 브라우저가 HTTP 요청을 보내고 서버가 응답한다는 흐름을 이해한다.
- [ ] HTML Form이 서버에 입력값을 전달하는 역할을 한다는 점을 알고 있다.
- [ ] Python 함수와 모듈 구조를 읽을 수 있다.

## 판단 방법

- 대부분 `예`라면 `BEGINNER-GUIDE.md`로 바로 진행합니다.
- SQL/관계형 DB가 낯설다면 B5-1의 PK/FK/CRUD Query 부분을 먼저 복습하면 좋습니다.
- Web Request/Form 흐름이 낯설다면 B4-1의 HTML/JavaScript 기본 흐름을 먼저 확인하면 좋습니다.

> **B5-1과 B4-1 CLEAR는 필수 조건이 아닙니다.** 필요한 DB·Web 기초를 이미 알고 있다면 바로 B5-2를 시작할 수 있습니다.
